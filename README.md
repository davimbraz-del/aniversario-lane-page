# 3ª Copa de FTV Amigos de Davi — Landing Page

Landing page oficial de convite para a 3ª Copa de FTV Amigos de Davi.

- **Data:** 30 de janeiro de 2027
- **Local:** Prainha Zona Sul
- **Horário:** a partir das 9h da manhã
- **Inscrição:** R$ 170

Abra `index.html` direto no navegador, ou publique via GitHub Pages (Settings → Pages → Deploy from branch `main` / root) para gerar um link público.

Os logos em `assets/` (`logo-white.png` e `logo-black.png`) foram exportados a partir do PDF oficial da logo enviado pelo cliente, preservando cores, proporções e identidade visual originais.
